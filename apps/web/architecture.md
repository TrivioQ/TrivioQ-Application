# TrivioQ Web (`apps/web`)

The Web app is the user-facing web portal that mirrors much of the mobile app's functionality for browser users.

## Technical Stack

- **Framework:** Next.js (App Router)
- **UI Library:** React, Tailwind CSS, Framer Motion (animations)
- **Key Dependencies:** Next-Intl (localization), React Query, Marked/React Markdown (rendering questions and math).

## Key Functionalities

- **Authentication:** Login and Signup pages.
- **Dashboard:** Central hub for the user, showing upcoming drops and quick stats.
- **Leaderboard:** Global user rankings.
- **Score History:** Detailed view of past scores and performance.
- **Settings:** User profile and account configuration.
- **Subscription:** Purchasing and managing subscriptions via the web.
- **Information Pages:** FAQ, Privacy, and Terms pages.
